Deep Metric Architecture

Siamese Convolutional Neural Network

Input Pair (x1, x2)
Shape: (90, 90, 1) Normalized [0, 1] Grayscale

• Conv2D(32, 3x3, ReLU) + MaxPool2D(2x2)
• Conv2D(32, 3x3, ReLU) + MaxPool2D(2x2)
↓ Metric Difference
L1 Feature Subtraction Layer
Diff = | W(x1) - W(x2) | (Invariant distance map)
↓ Classification Head
Decision Head & Sigmoid
• Conv2D(32, 3x3, ReLU) + MaxPool2D(2x2)
• Flatten + Dense(64, ReLU)
• Dense(1, Sigmoid) → Match Probability [0, 1]
